# 选题研究与爆款文案

> 输入一个选题，输出一份能直接写进组件的文案。
> 这篇是「怎么写」，`01-分镜文案模板.md` 是「写成什么形状」。

---

## 零、这套流程解决什么

**输入**：一个选题，比如「钱该花在对自己好的地方（家居类）」

**输出**：
1. 一张选题卡（人群 / 场景 / 冲突 / 可量化对象）
2. 3~5 条可借鉴的爆款拆解
3. 一句定调的风格卡
4. 一个 3 秒钩子（从 8 个模型里选）
5. 5 场景完整文案，每句标好落点
6. 发布文案 + 话题

**耗时**：熟练后 40 分钟，其中检索 15 分钟、写 20 分钟、检查 5 分钟。

## 一、选题拆解（3 分钟）

拿到选题先别写，先拆成四个格子。**四个格子填不满，说明选题还没想清楚。**

| 维度 | 要回答的问题 | 家居篇的答案 |
|---|---|---|
| **人群** | 说给谁听？年龄、生活状态 | 25~35 岁，独居或刚成家，有点积蓄但不算富裕 |
| **场景** | 在什么时刻会想起这件事？ | 下班回家、周末不出门、睡前刷手机 |
| **冲突** | 大家现在的做法 vs 应该的做法 | 钱花在别人看得见的（包、鞋、手机）vs 每天真正贴身的东西 |
| **可量化对象** | 能列出 4 个具体的、能量化的东西吗 | 椅子 8h / 灯 3h / 床品 8h / 锅 5h |

> **为什么要有"可量化"这一格**：清单场景需要 4 个能带数字的具体物件。
> 如果列不出来，说明选题太抽象，得往下切一层。
> 比如"极简生活"就列不出来，切到"极简生活先从哪四件东西开始"就能列了。

**产出：选题卡**

```
【人群】________
【场景】________
【冲突】现在大家都________，但其实应该________
【四个对象】①____ ②____ ③____ ④____
【一句话主张】________（≤20 字）
```

## 二、竞品检索（15 分钟，最重要的一步）

### 2.1 去哪里搜

| 平台 | 搜什么 | 为什么 |
|---|---|---|
| **抖音** | 同选题的高赞视频 | 看开头 3 秒和评论区，这是最直接的对手 |
| **小红书** | 同选题的图文/笔记 | 看标题句式和用户真实痛点表达 |
| **B站** | 同选题的长解说 | 看知识密度和逻辑结构，可以借骨架 |
| **微博** | 话题页 | 看争议点在哪，争议就是流量 |
| **行业报告** | 白皮书 / 趋势报告 | 拿权威数据当"反常识"场景的弹药 |

### 2.2 关键词怎么组

不要只搜选题本身，用**组合公式**，一次搜 6 组：

```
选题词 + 情绪词     家居 幸福感 / 家居 治愈
选题词 + 数字       家居 四件 / 家居 24小时
选题词 + 反常识     家居 后悔 / 家居 智商税
选题词 + 人群       独居 家居 / 租房 家居
选题词 + 时间       2026 家居趋势
选题词 + 平台梗     vibe知识大赏 家居
```

家居篇实际用到的 6 组：
`家居 幸福感`、`独居 家居 必备`、`家居 智商税`、`2026 家居消费趋势`、`情绪价值 消费`、`vibe知识大赏`

### 2.3 看什么（五个指标）

看到一条视频，不要只看点赞数，看这五样：

| 指标 | 怎么读 | 说明什么 |
|---|---|---|
| **点赞 : 评论** | 评论占比高（>3%） | 有共鸣或有争议，值得抄结构 |
| **前 3 秒的第一句** | 逐字记下来 | 这是人家花钱测出来的钩子 |
| **最高赞评论** | 看它说了什么 | 观众真正在意的点，往往和你以为的不一样 |
| **评论区吵架的地方** | 找对立观点 | 这是下一条视频的选题 |
| **收藏 : 点赞** | 收藏率高 | 干货属性强，说明"清单体"有效 |

### 2.4 记录表（边看边填）

| 视频/笔记 | 开头第一句 | 结构 | 金句 | 数据表现 | 可借鉴 |
|---|---|---|---|---|---|
| A | 我把 8000 的大衣退了 | 故事 → 转折 → 清单 | 钱花在看不见的地方 | 赞 12w / 评 8k | 开头用"退"制造动作感 |
| B | 独居三年，我只留了这 6 样 | 身份 → 清单 | — | 赞 5w / 收 2w | "只留"制造减法感 |
| C | 家居智商税 TOP5 | 反常识 → 排雷 | — | 赞 9w / 评 1.2w | 负向选题评论率更高 |

**产出一句话**：这三条的共同点是什么？那就是这个选题的"观众预期"，你要么满足它，要么故意反着来。

## 三、热点与热梗嫁接

### 3.1 三类热点，风险完全不同

| 类型 | 例子 | 生命周期 | 风险 | 建议 |
|---|---|---|---|---|
| **常青趋势** | "情绪价值"、"适我主义"、行业报告数据 | 1~3 年 | 极低 | **首选**，可以长期用 |
| **季节性节点** | 搬家季、618、年终总结、换季 | 2~4 周 | 低 | 提前 2 周做 |
| **时效热梗** | 网络流行语、影视二创梗 | 1~2 周 | 高 | 只在完全贴合时用 |

> **判断依据**：热梗的窗口期通常只有 1~2 周，过了再用会显得"网感差"。
> 所以做视频前先确认：这个梗现在还在热吗？搜一下最近 3 天的内容量。

### 3.2 能不能蹭：四条硬标准

蹭之前逐条过，**有一条不过就放弃**：

1. **相关性**——梗和选题共享同一种情绪吗？（不是同一个词，是同一种情绪）
2. **不冒犯**——涉及灾难、疾病、地域、性别对立、政治，一律不碰
3. **不尬**——把梗拿掉，这句话还成立吗？不成立就是硬蹭
4. **在窗口**——最近 3 天还有人用吗？

### 3.3 三种嫁接方式

| 方式 | 做法 | 例（假设用"人生齿轮没转，链条先掉了"） |
|---|---|---|
| **顺接** | 梗当引子，观点当主体 | "计划全崩了？先别急着修齿轮，把椅子换了" |
| **反接** | 拿梗当靶子打 | "都在说齿轮没转，其实是你的椅子先塌了" |
| **借词** | 只借句式，不借事件 | "钱没少花，是花错了地方" |

### 3.4 家居篇的真实判断：**不蹭热梗**

这是这套流程里最重要的一个示范——**不蹭也是一种专业判断**。

当时的判断过程：

| 候选梗 | 相关性 | 判断 |
|---|---|---|
| 人生齿轮没转，链条先掉了 | 讲计划崩盘，和"家居消费"没有共同情绪 | ✗ 硬蹭 |
| 不舒服文学 | 讲人际边界，和"对自己好"沾边但会跑题 | ✗ 容易歪楼 |
| 我是爷们 | 情绪宣泄，和家居调性完全相反 | ✗ 破坏风格 |
| **"情绪价值"（常青趋势）** | 45.89% 年轻人愿为情绪价值增加支出 | ✓ **采用** |
| **"适我主义 / 为自己而装"（小红书 2026 居住趋势）** | 直接对应"对自己好" | ✓ **采用** |

**结论**：家居篇用的是**常青趋势**而不是时效热梗。因为这条片子的气质是"安静、克制、有点书卷气"，任何强情绪的网络梗都会破坏它。

> **风格 > 流量**。一个不匹配的梗，能带来 10% 的播放，但会让 90% 的人觉得"这号不高级"。

### 3.5 数据怎么用（别堆，只放一个）

搜到的数据不要全塞进去，**只选一个，放在"反常识"场景里当弹药**。

家居篇可用的真实数据（2026）：

- 45.89% 的年轻人愿意为"情绪价值"增加支出（总台 12 万份问卷报告）
- 77.8% 的消费者愿意为能带来情绪价值的家居支付溢价（优居视界）
- 小红书《2026 居住趋势报告》提出"适我主义"：家要"为自己而装"
- 近四成用户装修前依赖 AI 规划（土巴兔 2026 报告）

**但家居篇最终一个数据都没用**——因为"8000 的大衣 400 元一次"这个自算的对比，比任何宏观数据都更有冲击力。
**能用自己算出来的数字，就别用报告里的百分比。**

## 四、风格统一（写之前先锁死）

风格不统一，观众会觉得"像几个人拼的"。**动笔前先填风格卡，写完逐条核对。**

### 4.1 风格卡

```
【人称】________（推荐：全程"你"或全程"我们"，不要混用）
【句长】________（推荐：≤15 字，超过就断句）
【语气】________（推荐：克制、平视、不说教）
【标点】________（推荐：不用感叹号，不用省略号堆叠）
【词汇】________（推荐：具体名词 > 抽象概念）
【禁用词】________（家人们、宝子们、绝绝子、YYDS、天花板、拿捏、绝了）
```

家居篇的风格卡：

| 项 | 设定 |
|---|---|
| 人称 | 前半段"我们"，后半段转"你" |
| 句长 | ≤15 字，多数 8~10 字 |
| 语气 | 克制，像朋友在饭桌上说的一句实话 |
| 标点 | 不用感叹号，用句号断句 |
| 词汇 | 全是具体物件（椅子、灯、床单、锅） |
| 禁用 | 所有网络流行语 |

### 4.2 一致性检查（写完通读，逐条打勾）

- [ ] 全片只有一个人称视角，中途没跳
- [ ] 所有数字是同一量纲（不要"8000 元"和"3 小时"混着比，要换算成单次成本）
- [ ] 金句只有 2 句，都在结尾，前面不抢戏
- [ ] 没有形容词堆砌（"超级舒适柔软亲肤"→"贴着皮肤的那层"）
- [ ] 没有出现任何禁用词
- [ ] 每句话单独拎出来，都像同一个人说的

## 五、开头 3 秒（决定 80% 的流量）

### 5.1 八种钩子模型

| # | 模型 | 句式 | 适合 | 例 |
|---|---|---|---|---|
| 1 | **数字反差** | `A 花 X，B 只花 Y` | 有明确价格/时长的选题 | 8000 的大衣，一次 400；4000 的床垫，一小时 1 块 4 |
| 2 | **反常识断言** | `最贵的 X，往往在 Y` | 有认知颠覆的选题 | 最贵的消费，往往发生在别人看不见的地方 |
| 3 | **身份代入** | `如果你是 X，这条一定要看` | 人群清晰的选题 | 独居的人，最该花钱的地方不在客厅 |
| 4 | **痛点直击** | `你是不是也 X` | 有普遍困扰的选题 | 腰疼了三年，才发现是椅子的问题 |
| 5 | **悬念提问** | `为什么 X 会 Y` | 有解释空间的选题 | 为什么住得越好，人越累 |
| 6 | **场景特写** | `凌晨两点，你 X` | 情绪类选题 | 凌晨两点，只有那盏灯还亮着 |
| 7 | **结论前置** | `直接说结论：X` | 干货类选题 | 直接说结论：先换椅子，再换手机 |
| 8 | **对比并列** | `别人都在 X，聪明人在 Y` | 有对立面的选题 | 别人在买包，聪明人在买床垫 |

### 5.2 三选一的标准

从 8 个模型里挑，按这三条筛：

1. **3 秒能读完**——主标题 ≤14 字，超过就砍
2. **有信息缺口**——读者必须想知道"为什么"，而不是"哦，然后呢"
3. **和结尾同构**——开头和结尾说的是同一件事的两面，首尾才咬得住

家居篇的筛选过程：

| 模型 | 文案 | 3秒读完 | 有缺口 | 首尾同构 | 结论 |
|---|---|---|---|---|---|
| 数字反差 | 8000 的大衣，一次 400 | ✓ | ✓ | ✗ | 留作场景 2 |
| 反常识 | 最贵的消费，在看不见的地方 | ✓ | ✓ | ✓ | **备选** |
| 身份代入 | 独居的人，最该花钱的地方不在客厅 | ✓ | ✓ | ✓ | 备选 |
| 场景特写 | 凌晨两点，只有那盏灯还亮着 | ✓ | ✗ | ✗ | 太慢，砍 |
| **结论前置+反问** | **钱，应该花在对自己好的地方** | ✓ | ✓ | ✓ | **采用** |

### 5.3 开头和 BGM 的关系

开头的三句话，**必须钉在前三拍上**：

| 拍 | 帧（112.85 BPM 下） | 内容 |
|---|---|---|
| 第 0 拍 | 2 | 标签 / 小字（给一个"这是系列片"的信号） |
| 第 1 拍 | 18 | 主标题第一行 |
| 第 2 拍 | 34 | 主标题第二行（强调色，这是真正的"钩"） |
| 第 3 拍 | 50 | 副文案（把主张说完整） |

> 注意：首拍在 **0.08s**，前面这 0.08 秒是静默的。
> 正好用来切黑 → 起画面，观众会感觉"画面是被第一个鼓点推出来的"。

## 六、把文案变成时间轴

写完文案，做一张对照表，**每句都要有落点**。没有落点的句子，就是会被观众忽略的句子。

| 文案 | 场景 | 小节 | 拍 | 帧 | 停留 |
|---|---|---|---|---|---|
| 钱，应该花在 | 钩子 | 0 | 1 | 18 | 16 帧 |
| 对自己好的地方 | 钩子 | 0 | 2 | 34 | 16 帧 |
| 不是更贵的生活，是更贴身的生活 | 钩子 | 0 | 3 | 50 | 80 帧 |

**两条硬规则**：

1. **一句不超过 2 拍**（1.06 秒）。超过就是句子太长，砍。
2. **每个场景最后一句，要留至少 1 小节的空**（2.1 秒），让观众消化。不留空 = 信息过载。

## 七、完整示例：家居篇从选题到成稿

### ① 选题卡
```
【人群】25~35 岁，独居或刚成家，有点积蓄但不算富裕
【场景】下班回家、周末不出门、睡前刷手机
【冲突】现在大家都买"别人看得见的"，但其实应该买"每天贴着身体的"
【四个对象】椅子 8h / 灯 3h / 床品 8h / 锅 5h
【一句话主张】钱花在看不见的地方，生活会在看得见的地方还给你
```

### ② 检索结论（3 条可借鉴）
- 爆款 A 用「我把 8000 的大衣退了」开头 → **动作感**比陈述句强，学到的是"用动词开头"
- 爆款 B 用「独居三年，我只留了这 6 样」→ **减法叙事**天然有吸引力
- 爆款 C「家居智商税 TOP5」评论率最高 → **负向选题**争议大，但会破坏温暖调性，放弃

### ③ 热点判断
- 时效热梗：全部放弃（理由见 3.4）
- 常青趋势：「情绪价值」「适我主义」→ 只作为底层逻辑，不写进文案
- 宏观数据：全部放弃，改用自算的单次成本

### ④ 风格卡
克制、短句、无感叹号、全具体名词、零网络流行语

### ⑤ 开头三选一
最终选「结论前置 + 反问」：**钱，应该花在 / 对自己好的地方**
理由：它同时是"结论"和"提问"，而且和结尾金句首尾同构。

## 八、AI 协作提示词（可直接复制）

### 提示词 1 · 竞品拆解
```
我在做一个抖音「Vibe知识大赏」风格的知识短视频，选题是【____】。
请帮我检索这个选题下近半年的优秀作品，按下面格式输出 5 条：
1. 开头第一句（逐字）
2. 内容结构（分几段，每段讲什么）
3. 一句金句
4. 点赞/评论/收藏的大致量级
5. 可借鉴的一个技巧
最后总结：这 5 条的共同点是什么。
```

### 提示词 2 · 热点判断
```
选题【____】。请列出 2026 年 10 月前后与它相关的 3 类热点：
常青趋势 / 季节性节点 / 时效热梗。
每一条标注：相关性（高/中/低）、风险、建议用还是不用，并说明理由。
如果全部不适合，请直接告诉我"不要蹭"，不要硬凑。
```

### 提示词 3 · 开头 10 版
```
给我 10 个开头第一句，主题【____】，要求：
- 每句 ≤14 字，3 秒内能读完
- 覆盖不同钩子模型（数字反差/反常识/身份代入/痛点/悬念/场景/结论前置/对比）
- 语气克制，不用感叹号，不用网络流行语
每条后面标注：模型名 + 它制造的信息缺口是什么。
```

### 提示词 4 · 风格统一改写
```
这是我的一段文案【____】。
我的风格卡是：人称【你】、句长≤15字、语气克制、不用感叹号、只用具体名词、禁用网络流行语。
请按这个风格重写，保持原意，不要增加新信息。
改写后列出你改动了哪几处、为什么。
```

### 提示词 5 · 卡点分镜表
```
BPM 112.85，一拍 0.5317s，首拍 0.08s，30fps。
把下面这段文案排成 5 个场景的时间轴，输出表格：
文案 / 场景 / 小节 / 拍 / 帧。
要求：每句不超过 2 拍，每个场景末尾留 1 小节空。
```

## 十一、常见错误对照

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 跳过检索直接写 | 写出来的都是"正确的废话"，没有新信息 | 先看 3 条爆款，找到别人没说的角度 |
| 见梗就蹭 | 硬蹭显得廉价，破坏账号调性 | 过四条标准，不过就放弃（不蹭也是判断） |
| 堆一堆宏观数据 | 观众记不住，还拖慢节奏 | 只放 1 个，或改用自算的对比数字 |
| 开头写"大家好" | 前 3 秒流失 60% | 第一句就是结论或冲突 |
| 形容词堆砌 | 听着像广告，没有画面 | 换成具体名词和动作 |
| 金句放中间 | 结尾平淡，没人截图 | 金句只在最后两句 |
| 每句都塞满 | 信息过载，看不完 | 每个场景末尾留 1 小节空 |
| 风格前后不一致 | 像几个人拼的 | 先填风格卡，写完逐条核 |
