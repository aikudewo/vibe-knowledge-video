## 二、核心技术详解

### 2.1 Canva 出图管道（唯一可行路径）

**问题**：Canva 生成的图拿不到原图。
- `www.canva.com/M/{id}` → 登录页
- `media.canva.com/v2/image-resize/...` → 需要签名，改尺寸即 403
- `get-assets` 的 thumbnail → 固定 200×112，太小

**可行路径**：

```
create-design（写清 brief，format: "Presentation (16:9)"）
   ↓ 轮询 get-create-design-async-job（wait_seconds 15 → 10）
export-design（format: png, width: 1920）
   ↓ 返回 export-download.canva.com 的 AWS 签名 URL
curl -sL -o out.png "<url>"
```

**关键**：导出链接是签名 S3 URL，**可以直接 curl 下载**，无鉴权。

**brief 的写法（元素清单法）**：

```
[底色] + [主体元素] + [辅助元素 3~5 个] + [构图：哪里留白给文字]
+ [色调：3 个色] + [质感：颗粒/玻璃/柔光/半透明] + [气质：清新/克制/高级]
+ 「不要任何文字」
```

**实测有效的两个 brief**：

> 丝绸曲面版：浅暖米白底，右侧半透明三维网格曲面，叠加细密等高线，下方柔和光晕与散落光点，左上角一组极细同心圆弧线，四角渐隐雾。左侧三分之一保持干净浅色留给文字。色调暖米白+淡青+浅金。细腻颗粒、半透明玻璃层次、柔和光影。

> 数据场版：浅青灰底，铺满极淡细密坐标网格，网格上漂浮半透明玻璃小球体，彼此用极细线连接，右上柔光弧线扫过，左下右上各一片渐隐雾。色调冷青灰+少量暖金。玻璃质感、柔光、半透明叠层。

**教训**：不写"左侧留白"，模型会把元素铺满，字就没地方放了。

### 2.2 配音（edge-tts）

```bash
pip install edge-tts
```

```python
import asyncio, edge_tts
async def main():
    c = edge_tts.Communicate("文本", "zh-CN-YunjianNeural", rate="-4%", pitch="-2Hz")
    await c.save("vo.mp3")
asyncio.run(main())
```

**音色选择**

| 音色 | 气质 | 适合 |
|---|---|---|
| `zh-CN-YunjianNeural` | 男，低沉 | 纪录片、知识 |
| `zh-CN-YunxiNeural` | 男，年轻 | 生活、轻松 |
| `zh-CN-XiaoxiaoNeural` | 女，标准 | 通用 |
| `zh-CN-XiaoyiNeural` | 女，活泼 | 种草 |

**必须分句生成**，不要整段。分句才能精确对齐字幕。

**语速**：`-3% ~ -4%` 最自然，`0%` 偏快，`-8%` 会拖。

**时长控制**：中文约 **4.2 字/秒**（rate -3% 时）。10 秒最多 42 字。

### 2.3 混音比例

| 轨道 | 音量 | 说明 |
|---|---|---|
| 人声 | **1.0** | 基准 |
| BGM（有旁白） | **0.15** | 只做底噪，听得见但不抢 |
| BGM（无旁白） | 0.32~0.55 | 可以当主角 |
| 音效 | 0.24~0.70 | pop 0.7 / tick 0.62 / chime 0.55 / whoosh 0.5 |

**铁律**：混音峰值 **< 0.9**，否则 AAC 编码会削波。

**验证**：`ffmpeg -i out.mp4 -ac 1 chk.wav` 后看 `np.abs(d).max()`。

### 2.4 程序化纹理（PIL）

```python
from PIL import Image
import numpy as np
W,H=960,540
rng=np.random.default_rng(1000+k)
a=(rng.random((H,W))*255).astype(np.uint8)
alpha=np.where(a>235,110,0).astype(np.uint8)   # 只保留 8% 的亮点
img=np.zeros((H,W,4),dtype=np.uint8); img[...,0:3]=255; img[...,3]=alpha
Image.fromarray(img,'RGBA').save('grain%d.png'%k)
```

生成 4 张，渲染时每 2 帧换一张 → 有"胶片抖动"感。
**注意**：颗粒用 `mixBlendMode: "overlay"`（深色片）或 `"multiply"`（浅色片），opacity 0.16~0.22。

```tsx
const FPS = 30;
const BEAT = 0.5314;            // 60 / 112.9
const beatF = (n: number) => Math.round(n * BEAT * FPS);
const barF = (bar: number, b = 0) => beatF(bar * 4 + b);
const sec = (s: number) => Math.round(s * FPS);
```

### 4.9 三维曲面（自写投影）

```tsx
const project = (x, y, z, rot, tilt) => {
  const X = x * Math.cos(rot) - y * Math.sin(rot);
  const Y = x * Math.sin(rot) + y * Math.cos(rot);
  const Y2 = Y * Math.cos(tilt) - z * Math.sin(tilt);
  const Z2 = Y * Math.sin(tilt) + z * Math.cos(tilt);
  const s = 1500 / (1500 + Z2 * 0.9);
  return { px: 1220 + X * s, py: 540 + Y2 * s, d: Z2 };
};
// z = 0.5 * sin(x*2.2 + t) * cos(y*2.0 - t)
```

## 五、环境与依赖

| 项 | 值 |
|---|---|
| Remotion | **4.0.536**（所有 @remotion/* 必须锁同一版本，去掉 `^`） |
| 扩展包 | transitions / animation-utils / motion-blur / shapes |
| 渲染 | Mac 直接 `npx remotion render`；Windows 才需加 `--browser-executable`（内置 chrome 下载损坏） |
| 并发 | `--concurrency=4`，1080p 约 300 帧/分钟 |
| ffmpeg | Remotion 自带的是**精简版**：没有 `acrossfade`/`amix`，不能封 m4a |
| 音频转换 | 用 numpy 做，输出 wav |
| TTS | edge-tts 7.3.1 |
| 图像处理 | PIL + numpy |

**ffmpeg 不能做的**：滤镜链（`-vf` 解析失败）、`select`、`fps`、`tile`、`acrossfade`、m4a 封装。
**能做的**：`-ss` 抽帧、`-ac/-ar` 转码、抽音轨、`-vf "scale=..."`（部分失败，改用 PIL）。

## 八、一句话总结

**Canva 管"看起来像什么"，Remotion 管"怎么动起来"，numpy 管"听起来怎么样"。**

三者之间用文件交接：Canva 出 PNG → Remotion 读 `staticFile` → 音频用 ffmpeg 转 wav 后 `staticFile`。
**没有任何一步依赖外部服务**，除了 Canva 出图和 edge-tts 配音。
