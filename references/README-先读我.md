# Vibe 知识视频工作流 · Mac 版

> 一套用代码（Remotion）生产抖音知识短视频的流程。
> 45 秒 / 一条镜头 / 三道闸门 / 一条命令验收。
>
> **版本 2.3** ｜ 打包日期 2026-10-26
>
> **要把这套流程交给另一个 AI 接手**：直接读 `AI-交接说明书.md`，
> 第 0 节有一段话可以原样复制给它。你自己上手就继续往下看。

## 二、五分钟跑通（macOS）

### 0. 装技能（30 秒）

```bash
mkdir -p ~/.workbuddy-ai/skills
cp -R "<本包路径>/skills/innovation-styles" ~/.workbuddy-ai/skills/
```

装完重启一次会话，在技能列表里确认 `innovation-styles` 已启用。
**这一步别跳**——`07` / `09` / `10` 三份文档的底稿都在它的 `references/` 里。
详见 `skills/安装说明.md`。

### 1. 装依赖

```bash
brew install node python ffmpeg
```

`ffmpeg` 是验收器要用的。`node` ≥ 18，`python` ≥ 3.9。

```bash
python3 -m pip install numpy
```

### 2. 建一个 Remotion 工程

```bash
npx create-video@latest --blank vibe-film
cd vibe-film
```

### 3. 把模板拷进去

```bash
cp <本包路径>/模板/*.tsx <本包路径>/模板/*.ts src/
cp <本包路径>/模板/package.json <本包路径>/模板/tsconfig.json .
```

> `模板/Neon.tsx` 里有字体常量（`SANS` / `SERIF`），**别的组件都 import 它**，
> 必须一起拷，不能漏。

### 4. 预览

```bash
npm start
```

浏览器打开后，左侧能看到 `Dazi45`、`Doudou45`、`DaziCover` 等 Composition。

### 5. 渲一版试试

```bash
npx remotion render src/index.ts Dazi45 out/test.mp4 \
  --crf=16 --pixel-format=yuv420p --color-space=bt709
```

### 6. 验收

```bash
python3 <本包路径>/工具/check_video.py out/test.mp4 --expect-fps 30 --expect-dur 45
```

看到 `✅ PASS` 就说明工具链通了。

## 四、五条不能破的规矩

这五条是从 31 条坑里提炼出来的，**破了任何一条，返工概率超过 60%**：

1. **全程一条镜头，0 次硬切。** 切点就是 PPT 换页感。要换风格就换光，不要换镜。
2. **每屏三层：主体 + 数据 + 注释。** 只有大字的一屏，删掉。正文 ≥ 26px、注释 ≥ 20px。
3. **先出 10 秒参考片给用户审，过了才做整片。** 改脚本 5 分钟，改成片 4 小时。
4. **交付前跑 `check_video.py`，PASS 之后还要从成片抽 4～6 帧人眼看。**
   PASS 只证明指标达标，不证明构图上没打架、段落之间没空拍。
5. **发抖音前跑 `check_words.py`，CRITICAL 必须清零。** 违禁词藏在 21px 注释行
   和"事实陈述"里，肉眼审不出来。

## 五、质量基线（拿到就照这个数交）

| 片 | 亮部均值 | 帧差均值 | 静止帧 | 音频峰值 |
|---|---|---|---|---|
| **大字理论**（有暗场，当前基准） | **17.53%** | **1.179** | 5（0.4%） | 0.811 |
| 大人玩小孩玩具（全程暖白） | 8.78% | 1.302 | 0 | 0.811 |
| 深睡自由（暖调） | 4.66% | 0.494 | 0 | 0.638 |

硬门槛：**静止帧 ≤ 2%、帧差均值 ≥ 0.5、亮部均值 ≥ 5%、音频峰值 < 0.97**。

> 有暗场的片子亮部会明显偏高（17% vs 8%），这是正常的。
> **跨片比较必须同分辨率**，而且不要把有暗场的和全程暖白的直接比。

## 八、两条使用提醒

**1. 所有"会变"的东西一律现搜，不靠记忆。** 平台规格、时间节点、价格、
行业数据、工具版本——搜完标来源和时间，搜不到就说搜不到，不要编数字。

**2. 文案不做营销。** 只写「一个事实开场 + 内容 + 金句」。
不借势平台趋势、不提大促节点、不用种草词话题、不写运营话术。
数字出处放评论区，不放在正文里当卖点。
