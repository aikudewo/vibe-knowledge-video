## 一、主推版本

**标题（封面大字 / 发布标题）**

```
花钱的品味，藏在家里最不起眼的四个地方
```

**正文**

```
8000 的大衣，一年穿 20 次，一次 400。
4000 的床垫，每天陪你 8 小时，一小时 1 块 4。

我们总在买"别人看得见"的东西，
却忘了每天真正陪着你的，
是那把坐了一整天的椅子、
那盏晚上只开一盏的灯、
那套贴着皮肤的床单、
还有那口愿意为你开火的锅。

它们不会出现在任何一张照片里，
可加起来，就是你的一整天。

钱花在看不见的地方，
生活会在看得见的地方还给你。

你最近一次"只为自己"花的钱，买了什么？
```

**话题**

```
#Vibe知识大赏 #家居 #消费观 #对自己好一点 #提升幸福感的好物 #独居生活 #理性消费
```

## 二、备选开头（A/B 测试用）

换开头不改片子，只改发布文案的第一句，用来测哪种钩子留人更好。

**A · 故事型**
```
我把买包的钱，换成了一张床垫。
朋友说我疯了，直到他们来我家睡了一晚。
```

**B · 判断型**
```
判断一个人会不会花钱，别看他的衣柜，看他家的椅子。
```

**C · 数字型**
```
真正贵的不是那件大衣，
是你每天坐 8 小时的那把椅子。
```

## 五、这套文案的结构说明

方便你换主题时照着改：

| 段落 | 作用 | 可复用的句式 |
|---|---|---|
| 前两行 | 用数字制造反差，让人停住 | `A，______，一次______。B，______，一小时______。` |
| 中段 | 列举具体物件，铺陈画面 | `我们总在买"______"的东西，却忘了______。` |
| 转折 | 把清单合并成一句判断 | `它们不会出现在任何一张照片里，可加起来，就是你的一整天。` |
| 金句 | 截图位，对仗结构 | `钱花在______的地方，______会在______的地方______。` |
| 互动 | 引导评论，别用"点赞关注" | `你最近一次"只为自己"花的钱，买了什么？` |

## 六、第二条：双11 篇（时机驱动型）

### 一、主推版本

**标题（封面大字 / 发布标题）**

```
双 11 别急着清空购物车，真正该买的只有五类
```

**正文**

```
今晚 8 点，双 11 现货开售。
先别付尾款，看完这条。

今年真正在涨的，就这五类：

① 床品
降温换被叠上大促，床品寝具 GMV 涨了近两倍。
磨毛四件套，300-600 拿下。

② 清洁电器
官方立减 + 店铺券 + 以旧换新国补，三层能叠。
2000-3000 档最划算。

③ 取暖
先算电费再买。
1500W 一天开 8 小时，一个月多出 100 度。

④ 厨房小电
一个就够，别买带屏幕的。

⑤ 换季收纳
买能叠的，别买好看的。

反过来，这三类别急着买：
灯具、沙发桌椅、空气净化器。
都是非当季，双 11 也不会便宜。

5000 块，能把一整个冬天换掉。

你今年购物车里，第一件是什么？
```

**话题**

```
#双11 #双11攻略 #家居好物 #避坑指南 #Vibe知识大赏 #消费观 #省钱
```

### 二、备选开头（A/B 测试用）

```
今晚 8 点，双 11 现货就开了。

```

```
双 11 有个规律：
越当季的越便宜，越非当季的越贵。
```

**C · 数据型**
```

五类在涨，三类在跌。
```

### 五、这条和上一条（家居篇）的差异

| | 家居篇（001） | 双11 篇（002） |
|---|---|---|
| 逻辑 | 观点驱动：钱该花在哪 | 时机驱动：什么时候买 |
| 钩子类型 | 结论前置 | 时间紧迫 + 数字 |
| 时效性 | 长期有效 | **今晚有效，过期需改开头** |
| 收藏动机 | 认同感 | 清单可照抄 |
